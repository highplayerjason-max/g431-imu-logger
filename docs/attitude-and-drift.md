# 姿态解算与漂移说明

记录日期：2026-09-21

## 当前算法

- `Core/Src/mahony.c`：Mahony 互补滤波（加速度计 + 陀螺仪，无磁力计）
- 参数：`kp = 0.5`，`ki = 0`（积分项默认关闭）
- 陀螺仪 ±2000 dps（61.03 LSB/dps），加速度计 ±16 g（2048 LSB/g）

这是 RM 开源工程里最常见的做法之一（与 Madgwick / 互补滤波同属一类）。
工作区 `开源/` 目录里只有北理工、哈工大、西工大、西南大学的 Altium 硬件文件，
没有可参考的姿态解算固件。

## IMU 安装方向映射（2026-09-21 加入）

本板 ICM-42688-P 是**竖着焊**的：板子平放时实测原始加速度
`ax=67, ay=-2057, az=33`，重力几乎全部落在传感器的 **-Y** 轴。

因此固件和 GUI 都对数据做如下重映射（右手系，取负号保证板子平放时显示水平）：

```
显示 X = 传感器 X
显示 Y = 传感器 Z
显示 Z = -传感器 Y
```

实现位置：

- 固件：`Core/Src/logger.c` 的 `idle_telemetry()`（实时姿态）
- GUI：`tools/imu_gui.py` 的 `_csv_worker()`（CSV 离线回放）

验证：板子平放时实时输出 `Roll 0.91°, Pitch -1.52°`（改之前为 61° / 4°）。

3D 显示的颜色约定：**红 = X，黑 = Y，绿 = Z**。

如果以后更换 IMU 安装方向，只需修改这一处映射并重新验证"平放时 roll/pitch ≈ 0"。

## 漂移从哪来

1. **陀螺零偏**（主要）：陀螺静止时输出不为 0，积分后表现为随时间线性增长的偏航误差。
   实测本板：`gx 0.12 dps, gy -1.03 dps, gz 1.15 dps`。
   仅 gz 的 1.15 dps 就会造成约 **69 deg/min** 的偏航漂移。
2. **温漂 / 随机游走**：零偏随温度变化，标定无法完全消除。
3. **没有磁力计**：ICM-42688-P 不含磁力计，偏航没有绝对参考，
   所以 **yaw 无法被长期修正**；roll / pitch 由重力参考，不会漂。

## 已实现的抑制措施

1. **上电陀螺零偏标定**：`Logger_Init()` 里调用 `calibrate_gyro_bias()`，
   静止采 500 个样本（2 ms 间隔，共 1 s）求均值，得到
   `g_gyro_bias_raw[3]` / `g_gyro_bias_dps_x100[3]`（调试可见）。
2. **实时遥测应用零偏**：`idle_telemetry()` 中先减去零偏再送 Mahony。
3. **重新标定命令**：UART 发 `C`；`Z`（调零）也会顺带重新标定。
4. **GUI 回放同样处理**：`tools/imu_gui.py` 加载 CSV 时用前 250 个样本的均值
   扣掉零偏后再做离线 Mahony。
5. **姿态调零**：GUI 的 ZERO 按钮 + MCU 的 `Z` 命令，把当前姿态设为零参考。

## 如果需要长期稳定的偏航角

按成本从低到高：

1. 每次任务前在已知朝向下重新 `Z` 调零（本方案，适合飞镖这种短时任务）。
2. 加装磁力计（如 IST8310，RM 板卡常见做法），在 Mahony/Madgwick 中启用
   `useMag = true` 做偏航修正。
3. 用外部参考（底盘 / 云台 / 视觉）提供绝对偏航。

## 实测数据（500 Hz × 10 s 静止日志）

| 项目 | 数值 |
|---|---|
| 全零样本 | 0 / 5000 |
| time_us 间隔 | 1999~2000 µs |
| 加速度模长 | 2048~2066 raw（≈1 g） |
| 陀螺均值（即零偏） | gx 0.20, gy -1.09, gz 1.17 dps |
| 纯积分偏航漂移（10 s） | 11.69°（≈70 °/min） |
| 扣除零偏后纯积分漂移 | -0.00° |
| Mahony 输出偏航漂移（10 s） | +1.87° |

结论：零偏标定能把"恒定偏置造成的漂移"消掉；
剩余漂移与绝对 yaw 需要磁力计或外部参考才能进一步解决。
